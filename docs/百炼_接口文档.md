# 阿里云百炼平台 API 接口文档

## 一、语音识别（ASR）

### 1.1 模型概览

百炼平台提供 Qwen-ASR 系列模型，包括：

| 模型名称 | 模型标识 | 适用场景 | 音频时长限制 | 调用方式 |
|---------|---------|---------|------------|---------|
| Qwen3-ASR-Flash | `qwen3-asr-flash` | 短音频识别 | ≤5分钟 | OpenAI兼容 / DashScope同步 |
| Qwen3-ASR-Flash-Filetrans | `qwen3-asr-flash-filetrans` | 长音频异步转写 | ≤12小时 | DashScope异步 |
| Qwen3-ASR-Flash-Realtime | `qwen3-asr-flash-realtime` | 实时语音识别 | 实时流 | WebSocket |

### 1.2 支持的音频格式

**文件格式**：`aac`、`amr`、`avi`、`aiff`、`flac`、`flv`、`mkv`、`mp3`、`mpeg`、`ogg`、`opus`、`wav`、`webm`、`wma`、`wmv`

**采样率**：任意（服务端会自动重采样为 16 kHz）

**文件大小**：≤10 MB

**时长限制**：≤5 分钟（Qwen3-ASR-Flash）

### 1.3 Qwen3-ASR-Flash（OpenAI 兼容模式）

#### 接口信息

- **地域**：北京 / 新加坡
- **HTTP 请求地址**：
  - 北京：`POST https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`
  - 新加坡：`POST https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions`
- **鉴权方式**：`Authorization: Bearer {API_KEY}`

#### 请求格式

```json
{
  "model": "qwen3-asr-flash",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "input_audio",
          "input_audio": {
            "data": "data:audio/webm;base64,{BASE64_ENCODED_DATA}"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

#### 请求参数说明

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| `model` | string | 是 | 模型标识，使用 `qwen3-asr-flash` |
| `messages` | array | 是 | 消息数组 |
| `messages[].role` | string | 是 | 固定为 `user` |
| `messages[].content` | array | 是 | 内容数组，只允许一个元素 |
| `messages[].content[].type` | string | 是 | 固定为 `input_audio` |
| `messages[].content[].input_audio.data` | string | 是 | 音频数据，支持 Base64 或公网 URL |
| `stream` | boolean | 否 | 是否流式返回，默认 `false` |

#### Base64 音频格式

**格式**：`data:{MIME_TYPE};base64,{BASE64_ENCODED_DATA}`

**常见 MIME 类型**：
- WAV：`audio/wav`
- MP3：`audio/mpeg`
- WebM：`audio/webm`
- OGG：`audio/ogg`

**示例**：
```
data:audio/webm;base64,SUQzBAAAAAAAI1RTU0UAAAAPAAADTGF2ZjU4LjI5LjEwMAAAAAAAAAAAAAAA...
```

**Python 编码示例**：
```python
import base64
from pathlib import Path

file_path = Path("audio.webm")
base64_str = base64.b64encode(file_path.read_bytes()).decode()
data_uri = f"data:audio/webm;base64,{base64_str}"
```

#### 响应格式（非流式）

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "qwen3-asr-flash",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "识别出的文本内容"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 0,
    "completion_tokens": 0,
    "total_tokens": 0
  }
}
```

### 1.4 DashScope 同步调用方式

#### 接口信息

- **HTTP 请求地址**：
  - 北京：`POST https://dashscope.aliyuncs.com/api/v1/services/audio/asr`
  - 新加坡：`POST https://dashscope-intl.aliyuncs.com/api/v1/services/audio/asr`

#### 请求格式

```json
{
  "model": "qwen3-asr-flash",
  "input": {
    "audio": "data:audio/webm;base64,{BASE64_ENCODED_DATA}"
  },
  "parameters": {
    "enable_itn": false,
    "enable_words": false
  }
}
```

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| `input.audio` | string | 是 | Base64 编码的音频或 URL 或本地文件路径 |
| `parameters.enable_itn` | boolean | 否 | 是否启用逆文本标准化，默认 `false` |
| `parameters.enable_words` | boolean | 否 | 是否返回词级时间戳，默认 `false` |
| `parameters.language` | string | 否 | 语言提示，如 `zh`、`en` |

## 三、重要注意事项

### 3.1 API Key 获取

- 访问：https://bailian.console.aliyun.com/
- 在控制台获取 API Key
- 北京地域和新加坡地域的 API Key 不同

### 3.2 地域选择

- **北京地域**：`https://dashscope.aliyuncs.com`
- **新加坡地域**：`https://dashscope-intl.aliyuncs.com`

### 3.3 限制说明

- Base64 编码会增大体积（约增大 33%），请确保编码后不超过 10MB
- Qwen3-ASR-Flash 支持最长 5 分钟音频
- 音频采样率任意，服务端会自动重采样为 16 kHz

### 3.4 代理设置

在调用百炼 API 之前，建议清除所有代理环境变量，避免连接问题：

```python
import os

# 清除代理环境变量
for key in ['HTTP_PROXY', 'HTTPS_PROXY', 'http_proxy', 'https_proxy', 'ALL_PROXY', 'all_proxy']:
    os.environ.pop(key, None)
```

## 四、快速开始

### 4.1 ASR 调用示例（Python + HTTP）

```python
import base64
import requests
from pathlib import Path

# 清除代理
import os
for key in ['HTTP_PROXY', 'HTTPS_PROXY', 'http_proxy', 'https_proxy']:
    os.environ.pop(key, None)

# 读取音频并编码
audio_path = Path("audio.webm")
base64_audio = base64.b64encode(audio_path.read_bytes()).decode()
data_uri = f"data:audio/webm;base64,{base64_audio}"

# 调用 API
url = "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
payload = {
    "model": "qwen3-asr-flash",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "input_audio",
                    "input_audio": {"data": data_uri}
                }
            ]
        }
    ],
    "stream": False
}

response = requests.post(url, headers=headers, json=payload)
result = response.json()
text = result["choices"][0]["message"]["content"]
print(f"识别结果: {text}")
```
